# 默认偏好（预设，不是规则）

这些做法来自一支 AI MV 的真实看片意见：试剪改了七版，又换第二支参考片剪了对比版。它们是一个起点，对应的数值在 `presets/default.json`。

怎么用：

- 当前这支 MV 里用户明确说的，优先于这里的任何一条。
- 新作品照样从这里起步，但彩蛋、帧率、字体、颜色这类是可选项，先问，不要默认每支都加。
- 新的看片意见先记进这支 MV 自己的项目记录（如 `project.json` 的 `records`）。只有用户明确说「以后都这样」，才改这份文件或预设。

引号里是看片时的原话，留着当例子。

- **片头不留黑场**：第 0 帧就给画面，参考片的黑场起不复刻（“片头我看是黑屏？没东西”）。第一帧也常被平台当预览图。
- **画面字卡到唱的字上**：大字卡、标题不要一整块正着砸在正中（“太正了，和画面不搭”）。每个字／词在唱到它时弹出（“字能卡点歌词，一个字一个字蹦出来”），各带一点倾斜，放画面空处、躲开人脸；暗场加辉光，亮场用粗描边加投影；歌里有拟声或重音就让字跟着晃（`wobble`）。
- **字色要从画面里跳出来**：先看素材主色，大字卡用主色的对比色，例如蓝白画面上用黄到橙（同色系时的反馈：“和背景太像 不够明显了”）。底部歌词可以和画面同色系，但要靠白字加深色外边拉开对比。
- **底部歌词**：先出几种样式的短样片让用户挑（`lyric_layer.py` 有 5 种）。唱到的字要跳得明显：一次实测定下的是上跳 22 像素（按 720 高算）、放大 30%、变亮色（`--set lift=22 --set pop_scale=0.3`）。时间必须用 DTW 逐字时间（见 SKILL.md 阶段 2）。
- **字体分工**：角色名、歌名可以用可爱的展示字体；正文字幕、片尾小字用粗黑体。只用许可允许商用和嵌入视频的字体，新字体下载前先问用户。
- **星芒闪慎用**：整屏放射光芒的闪光被否掉过（“看着很奇怪，不要了”）。
- **开头歌名卡、片尾字幕、彩蛋**：可以按常规做法各做一版给用户看，做法见下文；彩蛋先问。
- **署名只留一处**：片尾字幕和定格署名卡二选一。按实际用途署名（作词、作曲／演唱、画面分别用了什么），用户不想提的工具不提；素材许可要求署名的（例如 CC BY 系列）必须写上。
- **画面里看得出来的不贴名字**：画面已经交代清楚的人和物，不再贴标签（“不用加一眼也看得出来”）。字只放画面给不了的信息：署名、唱到的字、歌名。
- **定格署名卡不整帧换色**：照参考片把定格帧整帧换色调，效果很怪；更好的是画面保持原色定住，彩色手写名字底下垫一道斜的荧光马克笔条（`text_pop` 样式里的 `marker`）。拿不准时出两三张静帧让用户挑。
- **学手法，不照搬参考片的颜色**：单色段、整屏色块要换成本片的主色（参考片铺满黄色、本片是蓝白，就用浅天蓝三段色 `#14366E → #5AAEF5 → #F2FBFF`）。用户的原话：“我理解应该根据 MV 的配色来调整这个颜色的使用吧”。一闪而过的点缀色可以多样，整段铺开的颜色必须跟本片配色走。
- **先低清后 2K**：先出 1280×720 给用户看，用户说可以才出 2K；已通过的旧版在新版过审前不动、不替换。

## 歌名卡、片尾字幕和彩蛋的做法

- **歌名卡**：歌一开口就唱时，不要挤在第一句上，放到第一个没有人物的长镜头上，逐字弹出，下面一行小字署名。
- **片尾字幕和彩蛋**：歌淡出到黑以后接约 3 秒片尾字幕，再接 4–5 秒彩蛋，最好呼应开头（例：开头闹钟响 → 结尾闹钟又响 → 睁眼 → 倒放回闭眼）。这段比歌长，单独写一张剪辑表，`song` 用本地合成的音效轨，渲完和正片用 ffmpeg concat 拼接（视频直接拷贝，音频重编码），拼接后的成片再跑一次 `qa_render.py 成片.mp4 --duration <总秒数> --fps <帧率> --size <宽x高>`（拼接片没有单一的 EDL）。署名逐条要有出处，拿不准的写进汇报让用户定。
